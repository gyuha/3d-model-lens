# 3D Model Lens

3D 모델(glTF / GLB / STL)을 보고, 그 크기를 정직하게 읽어내는 데스크톱 앱. 이 컨텍스트의 언어는 "보는 것"과 "재는 것"을 엄격히 구분한다.

이 저장소는 VS Code 확장 `gyuha/vscode-3d-model-lens` 에서 갈라져 나온 독립 포크다. 뷰어의 언어는 그대로 계승하지만, VS Code 고유 개념(탭 · 명령 팔레트 · 워크스페이스 설정)이 차지하던 자리는 여기서 다른 것이 채운다.

## Language

**치수 (Dimensions)**:
모델 또는 선택한 메시의 바운딩 박스 X/Y/Z 크기. 상호작용 없이, 파일을 열면 곧바로 표시되는 값이다.
_Avoid_: 크기, 사이즈, 가로/높이/깊이

**측정 (Measurement)**:
사용자가 뷰어에서 두 점을 찍어 만든 하나의 거리 값. 목록에 담기고, 선택·삭제할 수 있는 개체다.
_Avoid_: 계측, 재기, 거리

**모델 단위 (Model Unit)**:
모델 좌표 1이 현실에서 뜻하는 단위. 파일 포맷이 이를 보장하지 않는 경우 사용자가 지정한다.
_Avoid_: 스케일, 축척, 단위계

**측정 모드 (Measure Mode)**:
캔버스 클릭이 카메라 조작이 아니라 [[측정]] 만들기로 해석되는 상태. 꺼져 있으면 이미 만든 측정은 남아 있되 감춰지고 만질 수 없다 — **치수**는 이와 무관하게 늘 표시된다.
_Avoid_: 측정 켜기, Enabled, 치수 모드

**정점 스냅 (Vertex Snap)**:
측정 점을 클릭한 삼각형의 세 정점 중 최근접 정점으로 붙이는 모드.
_Avoid_: 스냅핑, 자석, 그리드 스냅

**뷰어 패널 (Viewer Panel)**:
뷰어 안에 있는 지속 상태 UI — 단위 드롭다운, 측정 목록, 표시 토글, 그리고 표시 설정(소수 자릿수 · 시작 시 Inspector). [[메뉴 명령]] 과는 별개의 것이다.
_Avoid_: 컨트롤 패널, HUD, 사이드바

**패널 섹션 (Panel Section)**:
뷰어 패널 안에서 접었다 펼 수 있는 컨트롤 묶음. 치수와 모델 단위는 섹션이 아니라 늘 열려 있는 머리다 — 접히는 것만 섹션이다.
_Avoid_: 아코디언, 탭, 그룹, 접이식 메뉴

**내비게이션 큐브 (Navigation Cube)**:
뷰포트 왼쪽 위에 떠서 카메라가 지금 어느 방향에서 보고 있는지를 보여주고, 클릭하면 그 방향으로 카메라를 옮기는 조작기. 면·꼭짓점·화살표는 카메라 **자세**만 읽고 쓰지만, 홈 버튼은 `resetView()` 를 통해 거리(줌)와 타깃(팬)까지 되돌린다. [[뷰어 패널]] 과 달리 **지속 상태를 담지 않는다** — 저장되는 값은 숨김(`panelHidden`) 하나뿐이고 그것도 패널의 것이다. 씬 밖의 DOM 이므로 모델 클릭·[[측정]] 과 경쟁하지 않는다.
_Avoid_: 뷰큐브, 기즈모, 축 기즈모, 방향 표시기, 나침반

**정규 자세 (Canonical Pose)**:
[[내비게이션 큐브]] 의 한 영역이 화면을 정면으로 향하고 롤이 0인 카메라 자세. 면 6 + 꼭짓점 8 = 14가지다. 자유 자세 카메라에서는 같은 방향을 보는 자세가 무수히 많으므로, "롤 0" 이 그중 하나를 고르는 조건이다. **`TOP`/`BOTTOM` 2면은 예외다** — 시선이 월드 `±Y` 와 나란해 "롤 0"(= 화면 up 이 월드 `+Y` 에 가장 가깝다)이 정의되지 않으므로 축퇴 규약이 화면 up 을 월드 `∓Z` 로 못 박는다(`up · +Y = 0`).
_Avoid_: 표준 뷰, 프리셋, 스냅 각도

**뷰어 세션 (Viewer Session)**:
한 창에 한 모델이 열려 있는 동안 이어지는 것. **다른 파일을 열면 그 세션은 끝난다** — [[측정]] 이 폐기되는 경계가 정확히 여기다. 창을 여러 개 띄우면 세션도 여럿이고, 서로 상태를 나누지 않는다.
_Avoid_: 웹뷰, 탭, 창, 문서

**유휴 (Idle)**:
카메라·측정·표시 설정 중 아무것도 바뀌지 않아 새 프레임을 그릴 필요가 없는 상태.
_Avoid_: 정지, 대기, 비활성

**Inspector**:
Babylon.js가 제공하는 씬 디버그 UI(`scene.debugLayer`). 우리가 만드는 뷰어 패널과 다른 것이며, 우리 코드가 아니다.
_Avoid_: 디버그 레이어, 디버거, 개발자 도구

**앱 셸 (App Shell)**:
[[뷰어 세션]] 바깥에서 앱을 이루는 것 — 창, 네이티브 메뉴, 파일이 들어오는 경로, 설정 저장소. 뷰어가 웹 기술로 그려지는 것과 달리 이쪽은 OS 가 그린다. 원본 확장에서 이 자리를 차지하던 것이 VS Code 자체였다.
_Avoid_: 호스트, 네이티브 레이어, 프레임, 래퍼

**메뉴 명령 (Menu Command)**:
네이티브 메뉴바에 있는 토글 세 가지 — [[측정 모드]], Inspector, [[뷰어 패널]]. [[뷰어 패널]] 이 통째로 숨겨졌을 때 그것을 되살릴 수 있는 **유일한 경로**이므로 뷰어 밖에 있어야 한다.
_Avoid_: 단축키, 커맨드, 액션, 툴바

**빈 창 (Empty Window)**:
아직 모델이 열리지 않은 창의 상태. 창 전체가 파일을 받는 자리이며, 여기서만 파일이 세션의 시작이 된다.
_Avoid_: 시작 화면, 웰컴, 스플래시, 홈

**앱 테마 (App Theme)**:
배경 모드 `theme` 가 따르는 대상 — OS 의 라이트/다크 설정. 원본 확장에서 이 자리는 VS Code 편집기 배경색이었고, 그 차이가 색을 정의하는 방식 전체를 바꾼다.
_Avoid_: 시스템 테마, 다크 모드, 컬러 스킴
