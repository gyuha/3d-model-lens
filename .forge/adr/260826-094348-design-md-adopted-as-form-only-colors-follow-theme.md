# DESIGN.md 는 "형태만" 채택한다 — 색은 VS Code 테마를 따른다

레포 루트의 `DESIGN.md` 는 BMW M **마케팅 웹사이트** 디자인 시스템이다. 이 확장의 웹뷰 chrome
(뷰어 패널 · 측정 라벨 · 로딩 · 에러)에 이를 적용하기로 하면서, **어디까지 가져올지**를 정했다.

**색은 가져오지 않는다.** `DESIGN.md` 는 *"The system inverts almost nothing — there is no
light-mode marketing surface"* 라고 명시하며 canvas `#000000` + 흰 타입을 고정한다. 그런데 이
확장은 ADR `260822-195326` 에서 뷰어 배경을 `theme` | `light` | `dark` 3상태로 정했고 `light` 는
**순백(`#ffffff`)** 이다. 즉 **순백 뷰포트 위에 순흑 패널이 뜨는 조합이 정상 사용 경로에
존재한다.** 색까지 적용하면 라이트 테마 사용자에게 패널만 검은 벽돌로 떠서 "깨진 것"으로 보이고,
VS Code 확장의 테마 추종 관례와도 충돌한다. 그래서 모든 색은 `var(--vscode-*)` 를 유지하고,
`DESIGN.md` 의 hex 는 fallback 값으로만 쓴다.

**형태는 전부 가져온다.** `DESIGN.md` 스스로 브랜드의 실체를 형태로 규정한다 —
*"The rectangular silhouette IS the brand"*, 대문자 라벨의 트래킹은 *"non-negotiable"*, 그리고
브랜드 전압은 **사진**이 진다고 쓴다. 이 패널에는 사진이 들어갈 자리가 없다(뷰포트가 곧 사진
자리)므로, 남는 브랜드 신호는 넷이고 이 넷은 테마 색과 충돌 없이 전부 적용된다:

1. `rounded.none`(0px) — 각진 실루엣
2. 대문자 + 1.4px 급 트래킹의 "machined" 라벨
3. 굵기 대비 (다만 700/300 이 아니라 700/400 — ADR `260826-094300` 참조)
4. **M 트라이컬러 스트라이프** — 유일한 유채색 예외
   (**개정 2026-08-29**: task 18 의 [[내비게이션 큐브]] 축 삼각대 RGB 가 **두 번째** 예외다 —
   축 색은 상태가 아니라 식별자이고, 색에만 의존하지 않는다는 이 문서의 실제 요구는 `X`/`Y`/`Z`
   문자를 함께 찍어 지킨다. 근거는 ADR `260828-204140` 에 있다. 그 둘 말고는 없다.)

**M 트라이컬러는 브랜드 서명으로만, 두 군데에만 쓴다** — 패널 최상단 1줄, 로딩 화면 1줄.
`DESIGN.md` 의 *"The M tricolor is brand-identity-only — never extend it to system tokens"* 를
따르는 것이지만, 더 큰 이유는 **접근성**이다: 스트라이프로 "펼쳐진 섹션"이나 "선택된 측정"을
표시하는 안을 검토했다가 기각했는데, 그렇게 하면 상태가 **색에만** 의존하게 된다. 현재 코드의
`.measure-label.selected` 는 `outline` 으로 **형태**도 함께 바꿔 색맹 사용자에게도 전달되며,
그 성질을 후퇴시키지 않는다. 에러 화면의 가로줄만은 트라이컬러가 아닌 **M 레드 단색**을 쓴다 —
실패를 브랜드 순간으로 만들지 않기 위해서다.

## Considered Options

- **A. 전면 적용** (`#000`/`#fff` 고정) — 라이트 모드에서 깨진다. 기각.
- **B. 형태만** (채택) — 색은 테마, 형태·타이포·M 스트라이프는 DESIGN.md.
- **C. 패널 색을 뷰어 배경 3상태에 연동** — 다크 테마 + `light` 배경 조합에서 패널만 흰색이 되어
  에디터 나머지와 어긋난다. 설정 하나로 두 가지를 다투게 만드는 패턴은 ADR `260822-195326` 이
  이미 거부했다. 기각.

## Consequences

- **레포에 `DESIGN.md` 와 실제 구현이 색에서 어긋난 채로 공존한다.** 이 ADR 이 그 간극의 유일한
  설명이다. `DESIGN.md` 자체는 참조 문서로 그대로 두고 수정하지 않는다.
- Babylon 3D 측(그리드 색 `Color3(.45,.45,.45)`, 기본 머티리얼 `(0.78,0.78,0.8)`)은 이 결정의
  범위 밖이다 — ADR `260822-195326` 이 이미 별개 작업으로 분리해 두었다.
