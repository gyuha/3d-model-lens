# 3D Model Lens

glTF / GLB / STL 모델을 보고, **그 크기를 정직하게 읽어내는** 데스크톱 앱.

VS Code 확장 [`gyuha/vscode-3d-model-lens`](https://github.com/gyuha/vscode-3d-model-lens) 에서
갈라져 나온 독립 포크이며, 뷰어와 측정 기능은 그대로 계승한다.

## 지원 포맷

| 포맷 | 비고 |
|---|---|
| `.gltf` | 외부 `.bin` 과 텍스처를 함께 해결한다 |
| `.glb` | 바이너리 컨테이너 |
| `.stl` | ASCII / 바이너리 |

## 조작

드래그로 궤도 회전, 우클릭 드래그로 팬, 스크롤로 줌. 방향키도 드래그와 같으며 `Alt` 는 줌,
`Ctrl`/`Cmd` 는 팬이다.

왼쪽 위의 **내비게이션 큐브**는 지금 어느 방향에서 보고 있는지 보여주고, 클릭하면 그 방향으로
데려간다. 면 6개와 꼭짓점 8개가 클릭 대상이고, 둘레의 화살표는 90° 씩 돌리며, 오른쪽 아래의
작은 버튼은 처음 보던 자리로 되돌린다.

### 단축키 (Shortcuts)

숫자키로 같은 곳에 갈 수 있다. 큐브 면에 마우스를 올리면 그 면의 키가 보이고,
`View → Camera` 메뉴에도 같은 목록이 있다.

| 키 | 이동 |
|---|---|
| `0` | 기본 위치 — 자세 · 거리 · 타깃을 처음 상태로 (홈 버튼과 같다) |
| `1` | Top |
| `2` | Front |
| `3` | Right |
| `4` | Back |
| `5` | Left |
| `6` | Bottom |

입력칸에 커서가 있을 때는 숫자가 그대로 입력된다 — 카메라는 움직이지 않는다. `⌘`/`Ctrl` 이
섞인 조합도 이 앱이 가로채지 않는다. 꼭짓점 8개와 모서리 12개에는 키를 두지 않았다; 그쪽은
큐브를 직접 클릭한다.

## 치수와 측정

파일을 열면 바운딩 박스의 `X / Y / Z` 크기가 곧바로 나온다. 단위는 패널에서 고르며 기본
`Auto` 는 **glTF/GLB 를 미터로**, **STL 은 라벨 없이 숫자만** 보여준다 — STL 포맷에는 단위
필드가 없어 밀리미터라고 말할 근거가 없기 때문이다. 고른 단위는 **파일별로 기억한다**.

`Measure` 를 켜고 두 점을 찍으면 거리가 하나 만들어진다. 정점 스냅이 기본으로 켜져 있어
모서리 길이를 정확히 잴 수 있다. 측정은 **세션 범위**다 — 다른 파일을 열거나 창을 닫으면
사라지며, 파일로 저장되지 않는다.

바운딩 박스를 "가로 × 세로 × 높이" 라 부르지 않고 `X / Y / Z` 로만 적는 것은, glTF 로더의
좌표계 변환과 CAD 파일의 Z-up 관습 때문에 그 이름이 절반은 틀리기 때문이다.

## 설치

`npm run tauri build` 가 만든 `.dmg` 를 열고 `3D Model Lens.app` 을 응용 프로그램 폴더로
끌어다 놓는다. 설치하면 Finder 에서 `.gltf` · `.glb` · `.stl` 을 더블클릭해 바로 열 수 있다.

### 첫 실행 시 뜨는 경고

**이 앱은 코드 서명과 공증을 하지 않는다.** 그래서 처음 열 때 macOS 가
"개발자를 확인할 수 없기 때문에 열 수 없습니다" 라고 막는다. 우회하는 방법은 둘이다.

- 앱을 **우클릭 → 열기** 를 고르고 대화상자에서 다시 **열기** — 한 번만 하면 된다.
- 또는 시스템 설정 → 개인정보 보호 및 보안 에서 차단된 앱을 **그래도 열기**.

서명은 유료 개발자 계정이 필요하고 배포 채널이 정해지면 함께 다룰 일이라 지금은 하지 않는다.

## 개발

```sh
npm install
npm run tauri dev -- -- 경로/모델.glb    # 개발 (개발 서버가 함께 뜬다)
npm run tauri build                      # 배포용 .app / .dmg
```

`cargo run` 만으로는 동작하지 않는다 — 디버그 빌드는 개발 서버를 바라보므로 `tauri dev` 로
띄워야 한다. 빌드·검증·구조는 [CONTRIBUTING.md](./CONTRIBUTING.md) 에 더 적혀 있다.

## 검증

```sh
npm test           # 단위 (vitest)
npm run test:rust  # 설정 저장소 (cargo)
npm run test:e2e   # 브라우저 e2e (playwright)
npm run check:bundle && npm run check:split   # 번들 산출물 검사
```
